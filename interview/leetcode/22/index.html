22_括号生成[MEDIUM]

约 400 字大约 1 分钟

2026-03-24

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

示例 1：

输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]

示例 2：

输入：n = 1
输出：["()"]

解题思路

由于总共有 n 对括号，最终生成的字符串长度一定是 2n。

为了保证生成的括号一定是“有效”的，我们在添加括号时需要遵循两个核心原则：

  • 结束条件：构造的字符串长度达到 2n 时
  • 左括号的添加条件：只要已经使用的左括号数量小于 n，就可以继续添加左括号。
  • 右括号的添加条件：只有已经使用的右括号数量小于已经使用的左括号数量，才能继续添加右括号。

用一个 StringBuilder 不断构造字符串，用 open 和 close 两个变量记录当前已经使用的左括号和右括号的数量。

Java实现

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        StringBuilder path = new StringBuilder();
        backTrack(n, 0, 0, path, res);
        return res;
    }

/**
     * 回溯
     * @param res 结果集
     * @param path 当前正在构建的字符串
     * @param open 当前已经使用的左括号数量
     * @param close 当前已经使用的右括号数量
     * @param n 总共可以使用的括号对数
     */
    private void backTrack(int n, int open, int close, StringBuilder path, List<String> res){
        if (path.length() == 2*n){
            res.add(path.toString());
            return;
        }
        if (open < n){
            path.append("(");
            backTrack(n, open + 1, close, path, res);
            path.deleteCharAt(path.length()-1);
        }
        if (close < open){
            path.append(")");
            backTrack(n, open, close + 1, path, res);
            path.deleteCharAt(path.length()-1);
        }
    }

}
