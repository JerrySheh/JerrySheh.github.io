AI时代还有必要读书吗？

约 1902 字大约 6 分钟

人工智能

2026-04-12

Gemini 的推荐

我问 Gemini，如果向我推荐一本经济学读物，最推荐哪一本？

Gemini 推荐了《怪诞行为学》，我花了几天时间读了这套丛书的前两册。读完后，对于书中讨论的各种非理性话题，我也让 Gemini 帮我总结成下面两篇笔记：

  1. 《怪诞行为学：可预测的非理性》
  2. 《怪诞行为学2：非理性的积极力量》

这两本书的核心内容只有一句话：

传统经济学假设人类是理性的，人们总能根据可靠信息精确计算价值并实现利益最大化，但是事实证明，人类的实际决策过程远远不如理论假定的那般理性，现实行为受到环境、情绪、短视等多重因素的影响，也就是所谓的“非理性”。好在这种“非理性”是可以被预测的，只要我们承认自己可能存在非理性冲动，借助科学方法、有意识地去矫正，这种非理性有时候能转化为积极的力量为我们所用。

如果你恰好也对这个话题感兴趣，你会选择直接读我上面的两篇笔记，还是说会考虑去翻一翻原书？

AI时代还有必要读书吗？

最近在刷短视频的时候，我发现了一个有趣的现象。只要视频时长超过1分钟，很多人就不会看完原视频了，而是直接在评论区 @豆包 总结视频内容。

视频尚且如此，何况读书？

我开始思考，AI 已经这么强大了，一分钟就能帮我读完两本书，并且生成了翔实的笔记，我从 AI 总结笔记里面就能够吸收到书中的核心知识。还有必要浪费几天的时间去读原书吗？

我的答案是：只要时间允许，有必要。

实际上，在我读这本书的过程中，我最大的收获不是某个具体的非理性现象和应对的方法，而是无论遇到什么有趣的问题，作者丹·艾瑞里在每一章节中表现出来的一贯的科学严谨态度和做事的方法。

当遇到一个问题，他首先是观察，然后提出为什么的假设，之后设计一连串科学对照的实验，通过数据来证明（证伪）先前的假设，最终得出结论。这也印证了《毛选》中提到的：“一切结论产生于调查情况的末尾，而不是在它的先头”。

重要的是，这个收获是我的大脑在读书的过程中潜移默化形成的，而非来自书中某个具体的“知识点”。而且每当我读完一个章节，这种印记就加深一点。

从心理学的角度来说，我们的大脑非常擅长发现模式，大脑中充满了各种神经元，每当我阅读《怪诞行为学》的一个章节，尽管各个章节的内容各不相同，但作者的行事风格促使我大脑中跟“科学的做事方法”相关的神经元都会被激活一下。直到某一天淋浴的时候突然灵光一闪，顿悟原来这就是科学做事的方法。

有了这个大脑印记，以后我遇到一个问题，是不是就更容易跳出直觉，转向“观察-假设-实验（调查）-验证”的科学思维上来。

我想这种影响是产生了的，前几天我在网上看到一个帖子“ Vue 和 React 哪个更流行？”，我下意识地脱口而出，“在中国肯定是 Vue 更流行，但在国外 React 更流行”。但我很快意识到不对劲，这似乎是我的直觉，没有具体的数据，也没有经过调查，我怎么敢说出这么狂妄的结论？尽管在这个问题上，我的直觉可能是对的，但是不经思索和调查取证就下结论的做法，是不可取的。

回到这本书本身，如果我当时没有去读原书，而是只读 AI 总结笔记，我可能只是学习了“我们会有攀比的非理性冲动，应该审视物品真正价值而不是互相比较（第一章）”、“我们会高估自己拥有的东西的价值，应该刻意培养非拥有心态（第七章）”等等纸面知识，这些知识当然也很有用，但是由于跳过了读书时大脑的模式发现和不断刺激神经元的过程，纸面知识之外的东西（潜移默化地感悟到作者每一章对待问题的研究方法、以及阅读过程结合自身经历的感悟等）我们可能就体会不到了。

后来我意识到，只学习 AI 笔记，而不亲自读书，就会丢失大量在阅读过程中需要自主思考的细节、丢失激活神经元的机会。这就好比爬山，我们当然可以坐缆车直接到山顶，同样能欣赏到山顶的美景，但是自己爬上去的人会对这次活动更加印象深刻，也更能发现一路从山脊到山顶植被的变化。

旧事重提

我最近看到一个知识视频，博主分享了他的学习方法：先学习核心基础知识，当出现新知识或新理念的时候，就可以根据已知的基础知识来快速理解新知识。

看到这句话，我瞬间就想起了多年前我读过 Bruce Eckel 的一本书《On Java 8》，里面有一句话至今还印象深刻，他说：“如果我现在能很容易地理解一个新概念，那只是因为它是我已经知道的积累概念的一个变种。”

谁能料想我当年读这本书，除了学习 Java 知识外，还会对上面这句关于“学习方法”的句子印象深刻，以至于今天看到一个类似的表述时能瞬间回忆起来。假设很多年前已经有 AI 大模型，我让 AI 提炼这本书的核心内容，我想我会快速学会 Java 8，但永远不会记住这句话，领悟这种学习方法。

同一本书，不同的人阅读会有不同的领悟，但是不同的大模型只会有千篇一律的总结。

也许会有人说，那你在让 AI 总结这本书的核心内容的同时，顺便也让 AI 总结一下作者的行事风格，或者学习方法，不就行了？关键是，在真正读到那一句能让你醍醐灌顶的句子之前，你永远不会知道一本书带给你的真正价值是什么。这本书可能是作者的行事风格，那本书可能是作者随手一写的某个学习方法论，下一本书又可能是一个别人不会在意的边缘案例但跟你的成长相关因此对你很重要。
