给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。


示例 1：

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```


示例 2：

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

## 题目解析

**题意总结：**
给定两个已经按升序排好序的数组 `nums1` 和 `nums2`，长度分别是 `m` 和 `n`。我们需要找到这两个数组合并后形成的升序数组的**中位数**。
- 如果总长度 `m + n` 是奇数，中位数就是最中间的那个数。
- 如果总长度 `m + n` 是偶数，中位数就是最中间两个数的平均值。

**核心约束：**
题目明确要求时间复杂度必须为 `O(log(m + n))`。
这意味着我们**绝对不能**通过将两个数组合并或者使用双指针完整遍历到中点（这两种方法的时间复杂度都是 `O(m+n)`）。看到 `O(log)` 的时间复杂度要求，我们必须条件反射般地想到**二分查找（Binary Search）**。


## 解题思路

这里我们直接介绍最优雅、最优的方法：**划分数组法（对较短数组进行二分查找）**。这个方法不仅满足 `O(log(m+n))` 的要求，甚至优化到了 **`O(log(min(m,n)))`**。

### 核心思想：中位数的本质
中位数的本质是将一个集合划分为两个长度相等的子集，其中一个子集中的元素总是大于另一个子集中的元素。

假设我们将 `nums1` 在索引 `i` 处切开，将 `nums2` 在索引 `j` 处切开。
这样两个数组各自被分成了左右两部分：
```text
          左半部分           |          右半部分
nums1[0], ..., nums1[i-1]  |  nums1[i], ..., nums1[m-1]
nums2[0], ..., nums2[j-1]  |  nums2[j], ..., nums2[n-1]
```

为了让左半部分和右半部分成为中位数的分界线，必须满足以下两个条件：
1. **长度相等（或左边多一个）**：
   `i + j = (m + n + 1) / 2` 
   （加 1 是为了巧妙处理总长度奇偶性的问题，如果总长是奇数，左半部分刚好比右半部分多 1 个元素，中位数就是左半部分的最大值）。
2. **左半部分的所有元素 <= 右半部分的所有元素**：
   因为数组本来就有序，所以只需要保证交叉比较满足即可：
   - `nums1[i-1] <= nums2[j]` (nums1左边最大值 <= nums2右边最小值)
   - `nums2[j-1] <= nums1[i]` (nums2左边最大值 <= nums1右边最小值)

### 二分查找策略：
1. 为了提高效率和避免数组越界，我们**始终在较短的数组上进行二分查找**。假设 `m <= n`，我们在 `[0, m]` 的范围内二分查找 `i`。
2. 每次计算出 `i` 的中点后，由于长度固定关系，`j` 自然就是 `(m + n + 1) / 2 - i`。
3. 比较边界值：
   - 如果 `nums1[i-1] > nums2[j]`：说明 `nums1` 的左边分得太多/太大了，需要减少 `i`，于是缩小范围 `right = i - 1`。
   - 如果 `nums2[j-1] > nums1[i]`：说明 `nums1` 的左边分得太少了，需要增加 `i`，于是缩小范围 `left = i + 1`。
   - 否则，说明我们找到了完美的切割点 `i` 和 `j`！

### 复杂度分析：
- **时间复杂度**：`O(log(min(m, n)))`。我们只对较短的数组进行了二分查找。
- **空间复杂度**：`O(1)`。只需要几个指针变量，不需要额外的内存空间。


## Java 实现

在实际编写代码时，需要特别处理 `i=0`、`i=m`、`j=0`、`j=n` 这些切在数组边缘的特殊情况（我们通过给越界的元素赋予 `Integer.MIN_VALUE` 或 `Integer.MAX_VALUE` 来巧妙化解）。

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 保证我们在较短的数组上进行二分查找，这样可以优化时间复杂度到 O(log(min(m,n)))
        // 同时保证在计算 j 时不会出现负数下标越界
        if (nums1.length > nums2.length) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.length;
        int n = nums2.length;
        
        // 分割线左边需要的元素总个数
        // (m + n + 1) / 2 这种写法可以完美兼容总长度是奇数和偶数的情况
        int totalLeftElements = (m + n + 1) / 2;

        // 在 nums1 的区间 [0, m] 中进行二分查找
        int left = 0;
        int right = m;

        while (left <= right) {
            // i 是 nums1 的分割线（即 nums1 贡献给左半部分的元素个数）
            int i = left + (right - left) / 2;
            // j 是 nums2 的分割线（即 nums2 贡献给左半部分的元素个数）
            int j = totalLeftElements - i;

            // 处理边界情况：如果分割线在最左边，说明该数组没有元素贡献给左半部分，此时设为系统最小值
            // 如果分割线在最右边，说明该数组所有元素都贡献给左半部分，右半部分为空，设为系统最大值
            int nums1LeftMax = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int nums1RightMin = (i == m) ? Integer.MAX_VALUE : nums1[i];
            
            int nums2LeftMax = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int nums2RightMin = (j == n) ? Integer.MAX_VALUE : nums2[j];

            // 检查交叉条件：是否满足左半部分的最大值整体小于等于右半部分的最小值
            if (nums1LeftMax <= nums2RightMin && nums2LeftMax <= nums1RightMin) {
                // 找到了完美的分割线！
                
                // 计算左半部分的最大值
                int maxLeft = Math.max(nums1LeftMax, nums2LeftMax);
                
                // 如果总长度是奇数，中位数就是左半部分的最大值（因为左半部分比右半部分多一个元素）
                if ((m + n) % 2 == 1) {
                    return maxLeft;
                }
                
                // 如果总长度是偶数，中位数是左半部分最大值和右半部分最小值的平均值
                int minRight = Math.min(nums1RightMin, nums2RightMin);
                return (maxLeft + minRight) / 2.0;

            } else if (nums1LeftMax > nums2RightMin) {
                // nums1 的左边元素太大，说明划分的 i 取大了，应该往左找
                right = i - 1;
            } else {
                // nums2 的左边元素太大，说明 nums1 划分的 i 取小了，应该往右找
                left = i + 1;
            }
        }

        // 理论上不会走到这里，因为题目保证输入数组有效
        throw new IllegalArgumentException("输入的数组不是排好序的");
    }
}
```
