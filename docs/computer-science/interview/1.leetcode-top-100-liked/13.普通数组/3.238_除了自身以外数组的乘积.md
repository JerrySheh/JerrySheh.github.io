给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除了 `nums[i]` 之外其余各元素的乘积 。

请不要使用除法，且在 `O(n)` 时间复杂度内完成此题。

 

示例 1:
```
输入: nums = [1,2,3,4]
输出: [24,12,8,6]
```

示例 2:

```
输入: nums = [-1,1,0,-3,3]
输出: [0,0,9,0,0]
```
 

## 解题思路

自身以外的乘积，等价于：自身的左边的乘积 × 自身的右边的乘积 

两次循环：
- 第一次循环从左到右，初始化 `answer[]` ，得到左乘积
- 第二次循环从右到左，将 `answer[]` 乘以右乘积 `r`，得到左右乘积，即答案

算左乘积时， `i` 从 1 开始， 因为下标为 0 的元素左乘积为 1，不用算  
算右乘积时， `j` 从 `nums.length-2` 开始，因为最后一个元素的右乘积为 1，不用算 

## Java实现

```java
    public int[] productExceptSelf(int[] nums) {
        int[] answer = new int[nums.length];
        // 左乘积
        answer[0] = 1;
        for (int i = 1; i < nums.length; i++){
            answer[i] = nums[i-1] * answer[i-1];
        }
        // 右乘积
        int r = 1;
        for (int j = nums.length-2; j >= 0; j--){
            r = nums[j+1] * r;
            answer[j] = answer[j] * r;
        }
        return answer;
    }
```
