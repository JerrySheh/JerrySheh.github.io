给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

 

示例 1：
<img alt="" src="https://assets.leetcode.cn/aliyun-lc-upload/uploads/2021/01/02/addtwonumber1.jpg" style="width: 483px; height: 342px;" />
```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807.
```

 
## 解题思路

1. 遍历 l1 和 l2，只要 l1, l2 没遍历完，或者还有进位，就继续循环
2. 加法的本质： `v1 + v2 + carry（进位）`
3. 进位更新： `carry = sum / 10`
4. 当前位的值： `sum % 10`
5. 一直到两个链表全部循环完，且进位为 0 为止，如果一个完了一个没完，完了的那个补 0

```java
while(l1 != null || l2 != null || carry != 0){

}

```
6. 用 `dummy` 虚拟链表，用 `curr` 变量处理，最后返回 `dummy.next `

## Java 实现

```java
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;
    int carry = 0;
    // 只要 l1, l2 没遍历完，或者还有进位，就继续循环
    while(l1 != null || l2 != null || carry != 0){
        // 获取当前位的值，如果链表已经到末尾则补 0
        int val1 = (l1 == null) ? 0 : l1.val;
        int val2 = (l2 == null) ? 0 : l2.val;
        int sum = val1 + val2 + carry;   // 加法的本质
        carry = sum / 10;                // 更新进位
        curr.next = new ListNode(sum % 10);
        curr = curr.next;
        if (l1 != null) l1 = l1.next;
        if (l2 != null) l2 = l2.next;
    }
    return dummy.next;
}
```
