给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。

你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。
 
<img alt="" src="https://assets.leetcode.com/uploads/2020/10/03/swap_ex1.jpg" style="width: 422px; height: 222px;" />

示例 1：
```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```


示例 2：

```
输入：head = []
输出：[]
```


示例 3：

```
输入：head = [1]
输出：[1]
```

 

## 解题思路

1. 设置虚拟头节点 `dummy` ， `dummy.next` 指向 `head` ，并设置用于遍历的变量 `curr` 
2. 只要 `curr` 后面还有至少两个节点（即 `curr.next != null` 且 `curr.next.next != null`），就继续交换
3. 用临时变量保存 ①、②，以免后续调换后断开找不到
4. 让 ② 指向 ① ，让 ① 指向 ③
5. 将 `curr` 调到下一对的前面 （也就是 `dummy -> 2 -> 【1】 -> 3 -> 4`）

## Java 实现

```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode curr = dummy;
    // 只有当后面至少有两个节点时才进行交换
    while (curr.next != null && curr.next.next != null) {
        ListNode node1 = curr.next;
        ListNode node2 = curr.next.next;
        // 开始交换步骤
        // 1. temp 指向 node2
        curr.next = node2;
        // 2. node1 指向 node2 之后的节点 (node3)
        node1.next = node2.next;
        // 3. node2 指向 node1
        node2.next = node1;
        // 交换结束，将 curr 移动到下一对节点的前驱位置
        // 此时交换后的顺序是 curr -> node2 -> node1
        // 所以 curr 应该移动到 node1 的位置
        curr = node1;
    }
    return dummy.next;
}
```
