给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。



示例 1：

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```


示例 2：

```
输入：nums = [1]
输出：1
```


示例 3：

```
输入：nums = [5,4,-1,7,8]
输出：23
```


## 解题思路

- 定义状态：`dp[i]` 表示以 `nums[i]` 结尾的最大子数组和
- 基础情况：`dp[0] = nums[0]` （`nums[0]` 只包含一个元素，最大子数组和就是它本身）
- 状态转移： 遍历数组，当前最大，要么是历史最大+当前数字，要么“自立门户” 
    - `dp[i] = Math.max(dp[i-1] + nums[i], nums[i])`    


## Java 实现


```java
    public int maxSubArray(int[] nums) {
        int max = nums[0];
        int result = nums[0];
        for(int i = 1; i < nums.length; i++){
            int curr = nums[i];
            max = Math.max(curr, max + curr);
            if (result < max){
                result = max;
            }
        }
        
        return result;
    }
```
