给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `10^5`。

示例 1：

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

示例 2：

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

示例 3：

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

示例 4：

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

## 解题思路

双栈法，一个栈存字符串，一个栈存重复次数

遍历字符串，当遇到：

1. 遇到 `[` 时：将当前的字符串压入字符串栈，重复次数压入次数栈，暂存起来
2. 遇到 `]` 时：将次数栈值 `N` 取出，将当前字符串重复 `N` 次【A】，再将字符串栈原来暂存的字符串取出【B】，将【A】【B】两者拼接
3. 遇到 数字 时：因为可能遇到连续两个数字，如12，所以用 `multi * 10 + 当前数字字符`
4. 遇到 字母 时：直接拼接到结果字符串

## Java实现

```java
    public String decodeString(String s) {
        Stack<Integer> multiStack = new Stack<>();
        Stack<StringBuilder> resStack = new Stack<>();
        StringBuilder res = new StringBuilder();
        int multi = 0;
        for (char c : s.toCharArray()){
            if (c == '['){
                // 暂存
                resStack.push(res);
                multiStack.push(multi);
                // 重置
                multi = 0;
                res = new StringBuilder();
            } else if (c == ']') {
                // 将 res 重复多次，存入 temp
                StringBuilder temp = new StringBuilder();
                Integer lastMulti = multiStack.pop();
                for (int i = 0; i < lastMulti; i++) {
                    temp.append(res);
                }
                // 再拼接到上一次的结果上
                StringBuilder lastRes = resStack.pop();
                res = lastRes.append(temp);
            } else if (c >= '0' && c <= '9'){
                // 数字可能是多位的，例如 12[a]
                multi = multi * 10 + Integer.parseInt(String.valueOf(c));
            } else {
                res.append(c);
            }
        }
        return res.toString();
    }
```
