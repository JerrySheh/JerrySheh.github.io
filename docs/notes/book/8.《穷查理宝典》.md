查理·芒格（Charlie Munger），全名查尔斯·托马斯·芒格（Charles Thomas Munger，1924年1月1日—2023年11月28日），是美国传奇投资家、律师、慈善家，也是股神 沃伦·巴菲特 一生中最密不可分的黄金搭档与幕后智囊。

《[穷查理宝典](https://book.douban.com/subject/35557542/)》是彼得·考夫曼选编的一本关于查理·芒格的著作，其中第四章收录了芒格最重要的十一次演讲的内容。

摘录和笔记如下：

## 第一讲 在哈佛学校毕业典礼上的演讲（1986年6月13日）

### 如何获得过上“痛苦的一生”？ 

卡森的三味药：

1. 为了改变心情或者感觉使用化学物质（酒精、毒品等）
2. 妒忌
3. 怨恨

查理另开四味药：

1. 反复无常、不虔诚地做你正在做的事
2. 不从他人成果或失败的经验中广泛吸取教训（不管他们是古人还是今人）
3. 遭遇失败时意志消沉、一蹶不振
4. 不懂得反过来想

### 第一讲原文摘录

**反过来想、总是反过来想**。许多难题只有在逆向思考的时候才能得到最好的解决。

达尔文能够取得这样的成就，主要是因为他的工作方式。这种方式有悖于所有我列出的痛苦法则，而且还特别强调逆向思考：**他总是致力于寻求证据来否定他已有的理论，无论他对这种理论有多么珍惜，无论这种理论是多么得之不易。与之相反，大多数人早年取得成就，然后就越来越拒绝新的、证伪性的信息，目的是让他们最初的结论能够保持完整**。他们变成了菲利普·威利所评论的那类人：“他们固步自封，满足于已有的知识，永远不会去了解新的事物。”

爱因斯坦说他那些成功的理论来自“**好奇、专注、毅力和自省**”。他所说的自省，就是不停地试验与推翻他自己深爱的想法。

## 第二讲 论基本的、普世的智慧，及其与投资管理和商业的关系（1994年4月14日）

### 建立多元思维模型的框架

1. **跨学科学习**： 不能只用一种方法（如经济学）来解决所有问题，否则就会出现“在手里拿着铁锤的人看来，每个问题都像钉子”。
2. **掌握核心模型**： 必须要掌握八九十个来自不同学科的重要思维模型，并将经验悬挂在这些模型的框架上，才能真正理解事物并把知识派上用场。不要害怕，其中最核心的思维模型只有下面提到的几个。

### 核心思维模型

1. **数学**： 掌握复利原理、基本的排列组合原理以及决策树理论，将其作为日常思考的习惯。
2. **会计学**： 会计是商业的语言，但必须明白其局限性，它只是一种粗略的估算。
3. **心理学（极为关键）**： 人类的感知和认知器官容易受误导“短路”，懂心理学原理，既能防止自己受骗，也能用来理解和激励他人。
4. **微观经济学**： 把自由市场经济看作某种“生态系统”。分析规模优势的利和弊。
5. **技术与竞争**： 新技术有时候只能惠及消费者，而不能为企业所有者带来利润（如纺织业引进新机器）。但如果在新兴行业中处于领先，就能产生巨大的冲浪效应。

### 双轨分析法

- 第一轨：理性地分析，哪些因素真正控制了涉及的利益。
- 第二轨：评估有哪些潜意识因素（通常是心理因素）会自动促使大脑形成虽然有用但往往错误的结论。

### 普世智慧在投资领域的应用 

1. **坚守能力圈**： 必须弄清楚自己的优势在哪里，必须在自己的能力圈之内竞争。
2. **股市如同彩池投注系统**： 市场既有有效的部分，也有低效的部分。
3. **寻找错价机会并下重注**： 投资的秘诀在于寻找定错价格的赌注。
4. **投资伟大企业**： 投资那些拥有成长惯性、出色的管理体系和未被利用的提价能力（如可口可乐、迪士尼）的优质企业。
5. **长期持有**： 长期持有一家伟大公司的股票，能够极大地减少交易摩擦成本，并因为推迟缴纳资本利得税而获得每年1%到3%的额外收益，在复利作用下，这种优势极其惊人。

### 第二讲原文摘录

如果你们只是记得一些孤立的事物，试图把它们硬凑起来，那么你们无法真正地理解任何东西。如果这些事物不在一个理论框架中相互联系，你们就无法把它们派上用场。

微观经济学的伟大意义在于让人能够辨别什么时候技术将会帮助你，什么时候它将会摧毁你。

你们必须弄清楚你们有什么本领。**如果你们要玩那些别人玩得很好而你们一窍不通的游戏，那么你们注定会一败涂地**。

上天并没有赐予人类在所有时刻掌握所有事情的本领。但如果人们努力在世界上寻找定错价格的赌注，上天有时会让他们找得到。聪明人在发现这样的机会之后会狠狠地下注。他们碰到好机会就下重注，其他时间则按兵不动。就是这么简单。

好好把握少数几个看准的机会比永远假装什么都懂好得多。**如果从一开始就做一些可行的事情，而不是去做一些不可行的事情，你成功的几率要大得多**。

把赌注押在企业的质量上比押在管理人员的素质上更为妥当。换句话说，如果你们必须作选择的话，要把赌注押在企业的发展前景上，而不是押在管理者的智慧上。

帕斯卡说：“人类的头脑既是宇宙的光荣，也是宇宙的耻辱。”确实如此。人类的大脑拥有这种巨大的力量。然而它也经常出毛病，作出各种错误的判断。它还使人们极其容易受其他人操控。

## 第三讲 论基本的、普世的智慧（修正稿） （1996年4月19日）

### 第三讲原文摘录

你们需要的是在头脑里形成一个由各种思维模型构成的框架。然后将你们的实际经验和间接经验悬挂在这个强大的思维模型架上……使用这种方法可以让你们将各种知识融会贯通，加深对现实的认知。

如果你们的教授并没有教给你们正确的跨学科方法——如果每个教授都想过度地使用他自己的模式，对其他学科的重要模型弃之不用——你们可以自己改正那种愚蠢的做法。**他是个笨蛋，并不意味着你们也要成为笨蛋**。

如果你轻车熟路地走上跨学科的途径，你将永远不想往回走，因为那就像砍断你的双手。

严重的意识形态是最能扭曲人类认知的因素之一。如果你们年轻时深受意识形态影响，然后开始传播这种意识形态，那么你们无异于将你们的大脑禁锢在一种非常不幸的模式之中。你们的普遍认知将会受到扭曲。

如果你把准确、勤奋和客观当成你笃信的意识形态，那倒不要紧。

实际上，你应该弄清楚你知道什么，不知道什么。在生活中，还有什么比这个更有用的呢？

**当你不了解，也没有相关的才能时，不要害怕说出来**。

优秀的文学作品需要读者略加思索才能理解，那样它对读者的影响会很深，你会更牢固地记住它。这就是承诺和保持一贯性的倾向。**如果你动脑筋才懂得某个道理，你就会更好地记住它**。

## 第四讲 关于现实思维的现实思考？（1996年7月20日）

### 五个有用的观念

1. 简化任务的最佳方法一般是先解决那些答案显而易见的大问题。
2. 掌握并日常使用基本的数学（如复利原理、排列组合、基本的概率和决策树等），能够帮助人们更精准地量化和评估现实中的各种问题。
3. “反过来想，总是反过来想”。逆向思考，提前预见并避开失败的陷阱。
4. 必须以跨学科的方式思考。必须经常使用所有可以从各个学科的大一课程中学到的基本概念。
5. 注意多种因素的共同作用（Lollapalooza效应）,在商业和生活中，只有将多种强大的因素结合起来，才能产生指数级放大的巨大效应。

### 如何白手起家打造2万亿美元的企业（可口可乐）？

将心理学、经济学、数学等跨学科知识结合起来，形成强大的“现实思维”。

1. 利用心理学中的条件反射，建立强大的商标与条件反射。  
   - 操作性条件反射：提供卡路里、营养价值、出色的口感和提神醒脑的刺激效应。
   - 巴甫洛夫经典条件反射：广告，将产品与令人愉悦的事物建立联想。
2. 利用行为经济学和心理学中人的社会认同倾向。  
3. 引发自我催化反应（Lollapalooza效应）：巴甫洛夫条件反射 + 强大的社会认同效应 + 提神醒脑的绝佳口感。  
4. 逆向思考：如何避免毁掉这个伟大的品牌？ ——**成功后不要改变口味**。  

### 第四讲原文摘录

如果你们在思考问题的时候完全依赖别人，时常花钱请一些专业顾问，那么每当碰到你们那狭小的知识面之外的问题，你们将会遭遇很大的灾难。你们不但要浪费很多精力去处理复杂的合作问题，而且还将会遇到萧伯纳笔下那个人物所说的情况：“每个职业最终都是蒙骗外行人的勾当。”实际上，萧伯纳笔下的人物还低估了萧伯纳讨厌的那些行业的危害。通常来说，你的眼界狭窄的专业顾问并不是故意给你误事，而是他的潜意识偏见给你们带来麻烦。他的利益出发点跟你们不一样，所以他的认知往往是有缺陷的。他还拥有下面这句谚语所揭示的心理缺陷：“在拿着铁锤的人看来，每个问题都像钉子。”

泰勒之所以得到这个宝贵的教职，是因为泰勒经常取笑被芝加哥大学奉为圭臬的“理性人假设”。实际上，泰勒和我一样，认为**人们的行为通常是非理性的**，只有心理学能对其作出预测，所以**微观经济学必须借鉴心理学的研究成果**。

## 第五讲 专业人士需要更多的跨学科技能（1998年4月24日）

### 五个问题

#### **1. 广大专业人士是否都需要跨学科技能？**

是。单一的专业知识容易让人产生“激励机制引起的偏见”和“铁锤人倾向”。拥有跨学科技能可以有效减少这些认知错误。

激励机制引起的偏见，指的是“对我自己有利的，就是对客户和全社会有利的”的思维定式，案例：
  - 医疗领域：外科医生可能会为了赚钱和展示医术，去切除病人健康的胆囊，还坚信这是在为病人除根。
  - 商业领域：销售员为了拿到最高提成，会不惜损害顾客利益去推销劣质的旧机器。
  - 企业管理：雇员经常会把个人利益置于雇主利益之上，经济学家将这种偏见造成的后果称为“代理成本”。

#### **2. 我们的教育提供了足够的跨学科知识吗？**

不足够。现代教育过度局限于单一学科，学科之间壁垒森严、相互割裂，尤其是软科学领域。

#### **3. 对于大部分软科学，应该采取什么样的跨学科教育方法？**

借鉴飞行员训练模式：

1. 传授全面知识并要求熟练应用；
2. 培养正向和逆向思考技巧；
3. 养成核对“检查清单”的习惯；
4. 像使用飞行模拟器一样经常操练，以防遗忘。

#### **4. 过去50年来，精英学府跨学科教育有什么进展？**

虽然有些学校开始采用“拿来主义”借鉴其他学科知识（如法学院借鉴博弈论和经济学），但这种随意的方法缺乏系统性，效果并不完美。

#### **5. 如何加速跨学科教育？**

1. 将更多的课程列入必修课，而非选修课，意味着决定哪门课必修的人，自己必须熟练掌握大量跨学科知识。
2. 给学生提供更多用跨学科知识解决实际问题的实践机会。
3. 利用优秀的商业刊物（如《华尔街日报》）作为软科学的“飞行模拟器”来维持和操练智慧。
4. 避免聘用带有极端政治意识形态的教授。
5. 软科学应严格效仿硬科学（数学、物理、化学、工程学）的治学精神与方法，按基础性为学科排序并优先使用最基础的原理。

### 第五讲原文摘录

重大问题往往牵涉到许多学科。

在试图把优秀学生培养成优秀人才的精英教育中，如果想要得到最佳的结果，我们必须让学生学习大量的跨学科知识，持久地掌握能够应用自如的所有必要技能，拥有根据实际情况综合熟练使用各种知识的能力，以及证明代数问题用到的那些正向思考和逆向思考的技巧，再加上核对“检查清单”的终身习惯。若要获取全面的普世智慧，没有别的办法，更没有捷径。

**“所有必要技能”这个概念让我们明白，我们无需让每个人都像拉普拉斯那样精通天体力学，也无需让每个人都精通其他各门学科。事实上只要让每个人掌握每个学科中真正的大道理就够了**。这些大道理并不算多，它们相互之间的关系也没那么复杂，只要拥有足够的天赋和时间，大多数人都能够拥有一种跨学科知识。

我们有这么多优秀的教师、学生和时间，还有许多成功的跨学科大师作为楷模，却仍然未能将“铁锤人倾向”的负面影响最小化，这说明如果我们安于现状，或者害怕改变，不努力去争取，你就无法大赢。

软科学界逐渐发现，如果几个来自不同学科的教授合作研究，或者一个教授曾经取得几个学科的学位，那么做出的研究成果会更好。但是另外一种做法的效果通常是最好的，那就是补充法，或者“拿来主义”法，这种方法鼓励各个学科无论看中其他学科什么知识，只管拿过来用。这种方法能够取得最好的效果，也许是因为它避开了扎根在传统中的学术争论，以及在单一学科中固步自封引起的蠢行——而这正是我们现在致力于改正的。

在这里我想解释一下我所说的治学精神与方法，它包括下面四点：
1. 你们必须依照基础性给各个学科排序，并按照顺序使用它们。
2. 不管是否喜欢，你们必须熟练掌握并且经常使用这四门基础学科最重要的内容，而且对于那些比你们自己的学科更加基础的学科，要给予特别的关注。
3. **在吸收不同学科的知识时，要弄清楚那些知识是怎么来的**，而且不要背离“经济原则”，只要有可能，首先通过自己或其他学科中更为基本的原理对现象进行解释。
4. 但是如果第3步并没有对现象解释提供有用的新观点，你们可以**通过提出假设和进行验证确立新的原理**，就像旧的原理创建的方式一样。但你们不能使用任何与旧的原理冲突的新原理，除非你们能够证明旧的原理是错误的。

在商界和科学界，有条往往非常有用的古老守则，它分两步：（1）找到一个简单的、基本的道理；（2）非常严格地按照这个道理去行事。

在利用非正式的教育来弥补自己的知识缺陷的过程中，我发现，虽然我的学习意愿并不算非常强烈，但在这种基本治学精神与方法的指引之下，我的能力得到了极大的提高，这远远超乎我原本的意料。
