经济学十大原理由美国经济学家 N·格里高利·曼昆（N. Gregory Mankiw）在其著作[《经济学原理》](https://book.douban.com/subject/37527745/)中提出。这十大原理构成了经济学（微观与宏观）的基础框架。

## 一、人们如何做出决策

### **原理一：人们面临权衡取舍**

为了得到一样我们喜欢的东西，通常不得不放弃另一样我们喜欢的东西。做出决策要求我们在不同目标之间进行权衡。

对于个人：
1. 学生需要权衡学习时间和娱乐时间，在某件事情上多花1分钟，就意味着在其他事情上少花1分钟；
2. 父母需要权衡家庭收入的安排，在某种用途上多花1元，就意味着在其他用途上少花1元；

对于社会：
1. 社会需要权衡“大炮与黄油”，当国防支出增加时，用于改善民生的支出就会减少；
2. 社会需要权衡环境质量与经济增长，当环保要求提高，企业成本就会增加，经济增长就会放缓；
3. 社会需要权衡效率（把经济蛋糕做大）与平等（如何分割这块蛋糕）。

### **原理二：某种东西的成本是为了得到它所放弃的东西**

在做出决策时，人们必须认识到采取某项行动的真正成本是 **机会成本（Opportunity Cost）**。

例如，上大学的成本不仅包括学费和书本费，还包括因为上学而放弃的潜在工资收入。

> 上大学的成本绝不包括住宿费和伙食费，因为即使不上大学也需要住宿和吃饭。只有当上大学的住宿和伙食比不上大学更高时，才计入成本。

### **原理三：理性人考虑边际量**

经济学家通常假设人是理性的。对于理性人来说，生活中的许多决策很少是非黑即白的，还存在灰色的地带。**决策往往是对现有行动计划进行微小的增量调整，这些调整被称为边际变动（Marginal Changes）**。

例如：  
1. 吃午饭时的决策不是完全不吃或者饱餐一顿，而是是否再多吃一口；
2. 考试复习时的决策不是完全不复习或者24小时复习，而是是否再多复习一小时；

**当且仅当一种行为的边际收益大于边际成本时，一个理性决策者才会采取行动**。

例如：  
1. 手机通讯套餐内的通话时间，我们会随便打，但套餐外每多打一分钟我们都要掂量一下；
2. 飞机临起飞前还有空位，航空公司愿意降价多卖给一个乘客；
3. 水对于生存很重要，但是水太多了，多一杯水的边际收益微不足道，所以水很便宜；钻石虽然对于生存不重要，但钻石稀缺，多一颗钻石的边际收益很高，所以钻石很贵。

### **原理四：人们会对激励做出反应**

当成本或收益发生变动时，人们的行为也会随之改变。激励改变了成本或收益，所以在决定行为方面起着中心作用，也是公共政策设计的重要考量因素。

例如：
1. 汽油价格上涨，人们会少开车，多乘坐公共交通；
2. 汽油税增加，会鼓励人们购买新能源汽车；

## 二、人们如何相互作用

### **原理五：贸易可以使每个人的状况都变得更好**

贸易并不是一场一方赢而另一方输的零和游戏。

通过贸易，每个人或国家都可以专门从事自己最擅长的活动（即拥有 **比较优势（Comparative Advantage）** 的领域），从而以较低的成本享受更丰富多样的物品与服务。

### **原理六：市场通常是组织经济活动的一种好方法**

在市场经济中，没有中央计划者来分配资源。相反，成千上万的家庭和企业在市场上相互交易，价格和个人利益引导着他们的决策。

经济学家亚当·斯密 (Adam Smith) 在《国富论》中提出，市场交易就如同有一只 **看不见的手** 在指引着经济活动走向整体的效率和均衡。价格会自发调整，指引买卖结果，从而使整个社会福利最大化。斯密的观点有一个重要推论，即政府不应该过度干预市场，否则会破坏这种自发秩序。

### **原理七：政府有时可以改善市场结果**

虽然市场通常是有效的，但它并不能解决所有问题。当出现外部性（如污染）或市场势力（如垄断）时，会导致市场失灵。

在这些情况下，政府可以通过合理的公共政策（如法规、税收或反垄断法）来干预经济，以促进效率和公平。

> 政府有时可以改善市场结果，但这并不意味着它总会这样。公共政策并不是天使制定的，而是由不完善的政治程序制定的。有时所设计的政策只是为了有利于政治上有权势的人。有时政策是由动机良好但信息不充分的领导人制定的。经济学帮助我们更好地判断一项政府政策什么时候是合理的（提高了效率或促进了平等），而什么时候是不合理的。

## 三、整体经济如何运行

### **原理八：一国的生活水平取决于它生产物品与服务的能力**

世界各国生活水平的巨大差异，以及同一国家不同时期生活水平的变化，几乎都可以归因于 **生产率（Productivity）** 的差别。生产率越高，即每一单位劳动投入所生产的物品与服务数量越多，该国的生活水平通常就越高。

在考虑任何一项政策如何影响生活水平时，关键是要分析这项政策如何影响我们生产物品与服务的能力。为了提高生活水平，决策者需要通过让工人受到良好的教育、拥有生产物品与服务需要的工具以及获取最好的技术来提高生产率。

### **原理九：当政府发行了过多货币时，物价上升**

当一个国家的政府创造并发行了大量本国货币时，货币的价值就会下降，导致经济体中物价总水平持续上升。这就是 **通货膨胀（Inflation）** 的根本原因。

### **原理十：社会面临通货膨胀与失业之间的短期权衡取舍**

大多数经济学家这样描述货币增加对经济的影响：

```
货币增加 -> 需求增加 -> 价格上涨 -> 企业增产 -> 雇佣更多人 -> 失业率下降
```

在短期内（通常为一两年），宏观经济政策（如增加货币供应或扩大政府支出）往往会刺激需求，进而降低失业率，但同时也会推高物价水平导致通胀。
